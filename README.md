# PowerTies Consulting Group — Website

Static website for PowerTies Consulting Group LLC and The Guild of Honour.

## Pages
- `index.html` — Home page
- `about.html` — About Keith Tully

Both pages are self-contained HTML (CSS and JavaScript inline; fonts from Google Fonts). No build step is needed.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.
